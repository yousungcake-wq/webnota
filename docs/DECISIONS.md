## 020 한글 검색에 es-hangul 사용 (2026-11-27)

- 결정: 검색 전반(전문 검색 색인, 제목 필터, 메뉴 필터, 강조)에 토스의 `es-hangul`(MIT)로 자모 분해·초성을 적용합니다.
- 이유: 사용자 요청. 입력 중인 글자("삭" → 사과)와 초성 검색은 한국어 사용자에게 기본 기대치입니다. 직접 구현보다 검증된 라이브러리가 안전합니다.
- 방식: 색인은 단어의 모든 접미사를 자모·초성으로 넣고, 검색어 자모를 접두어로 맞춥니다(부분 일치 + 입력 중 일치). 자모 일치는 음절 시작에서만 인정해 오탐을 줄입니다.
- 비용: 색인 크기 증가(한글 단어당 접미사 수만큼), 에디터 청크 +1.6KB. 초기 번들은 검색 화면을 지연 로드해서 오히려 0.6KB 줄었습니다.

## 021 공유 단위 = 스페이스, 공유 스페이스마다 별도 저장소 (B안, 2026-11-27)

- 결정: 협업(SH)은 Notion 팀스페이스처럼 스페이스 단위로 합니다. 개인 스페이스는 홈 저장소, 공유 스페이스는 각자 비공개 저장소(`webnota-space-<slug>`)이고, 멤버 = 그 저장소의 GitHub 협업자입니다. 페이지 공유 = 공유 스페이스로 옮기기. 한 워크스페이스가 여러 저장소와 동기화합니다(SY-08).
- 이유: 사용자 결정. GitHub 권한이 저장소 단위라 페이지 단위 공유는 불가능하고, 워크스페이스 = 저장소 1개(A안)면 초대 시 개인 페이지까지 모두 노출됩니다.
- 비용: 다중 저장소 동기화, 스페이스 간 이동(복사→푸시 확인→삭제), `space` 문서(spec/02 §2.1)와 schemaVersion 증가, 저장소를 넘는 참조 처리. M9가 커집니다.
- 제약: 편집자는 GitHub 계정 필요(비회원은 웹 게시로 읽기만), 읽기 전용 게스트는 조직 저장소에서만, "링크 있는 누구나 편집" 불가. PAT는 저장소마다 권한을 줘야 해서 GitHub App을 권장.
- 검토한 대안: A안(워크스페이스 = 저장소 1개, 단순), 페이지별 저장소(저장소 폭증), 종단 간 암호화로 한 저장소 안에서 권한 흉내(키 관리 복잡, 검색·실시간 어려움).

## 022 CSS 예산: 시작 CSS ≤ 10KB + 전체 CSS ≤ 35KB (2026-11-28, M7-00)

- **배경**: spec/10의 "CSS 전체 ≤ 25KB(즉시)"는 PoC 때 CSS가 하나뿐이던 기준입니다. 지금은 대부분이 기능별 지연 CSS(에디터 4.6, DB 4.1, 보드·캘린더·이미지·임베드·인라인 DB 등)라, 한 번에 다 내려받지 않는데도 합계가 24.4KB로 예산을 거의 채웠습니다.
- **결정**: 실제로 첫 화면을 막는 **시작 CSS(초기 청크의 CSS)를 10KB**로 묶고(현재 약 5.9KB), 기능 CSS 전체는 지나친 증가를 막는 가드로 **35KB**까지 둡니다. 지연 CSS도 각 기능 청크와 함께 로드되므로 그 기능의 체감 속도에는 청크 예산(JS)과 함께 영향을 줍니다 — 기능 CSS는 그 컴포넌트에서만 import.
- **대안**: CSS를 줄이기만 하기 — 화면이 늘수록 계속 반복해야 하고, 지연 CSS는 첫 로드에 영향이 없음.


## 023 앱 업데이트: 자동 활성화 대신 "대기 후 알림" (2026-11-28, M7-10)

- **배경**: 지금까지 서비스 워커는 `registerType: 'autoUpdate'`(새 워커가 바로 활성화하고 옛 캐시를 지움)였습니다. 열려 있는 앱은 옛 버전으로 돌아가는데 옛 지연 청크 파일이 캐시와 GitHub Pages에서 사라져, 오래 열어 둔 탭에서 새 기능 청크 로드가 실패할 수 있었습니다.
- **결정**: `registerType: 'prompt'` + 직접 등록(`platform/sw.ts`, `injectRegister: false`). 새 버전은 설치 후 **대기**하고, 앱은 "업데이트가 준비되었습니다 [새로 고침]" 토스트만 띄웁니다. 버튼을 누르면 `SKIP_WAITING` → 제어권이 바뀌면 새로 고침. 누르지 않으면 모든 탭을 닫은 다음 실행에 새 버전이 적용됩니다. 편집 중 강제 새로 고침은 없습니다. 1시간마다·앱이 앞으로 올 때 새 버전을 확인합니다.
- **대안**: workbox-window(`virtual:pwa-register`) — 같은 일을 하지만 시작 번들에 약 3KB가 더해짐.
