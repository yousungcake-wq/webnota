# 09. 설정, 알림, 가져오기·내보내기, 템플릿 (`ST` `NT` `IO`)

## 1. 설정 (`ST`)

AppFlowy `settings/pages/*`에서 요금제, AI, 클라우드 설정을 뺀 구성입니다.

| ID | 섹션 | 항목 | 마일스톤 |
|---|---|---|---|
| ST-01 | 계정 | GitHub 계정(아바타, 이름), 연결 방식(OAuth/PAT), 연결 해제, 다른 계정으로 전환 | ✅ / M1 |
| ST-02 | 워크스페이스 | 이름, 아이콘, 저장소 정보(링크, 크기), 워크스페이스 목록·추가·제거 | M1 |
| ST-03 | 멤버 | SH-02 | M9 |
| ST-04 | 동기화 | 상태, 지금 동기화, 동기화 로그, 실시간 협업 상태, 저장소 기록 정리 | M0 / M6 / M10 |
| ST-05 | 화면 | 테마(시스템/라이트/다크 ✅), 강조 색상, 글꼴(UI/본문), 글자 크기 배율(90~130%), 날짜 형식, 시간 형식(12/24h), 주 시작 요일, 언어(한국어/English) | M11 (테마 ✅) |
| ST-06 | 사용자 지정 테마 | 색 토큰 JSON 가져오기/내보내기 (AppFlowy `theme_upload`) | M11 (P2) |
| ST-07 | 단축키 | 목록, 검색, 다시 지정, 기본값 복원 (AppFlowy `settings_shortcuts_view`) | M11 |
| ST-08 | 데이터 관리 | 저장 공간 사용량, 캐시 지우기, 전체 내보내기(zip), 가져오기, 로컬 데이터 삭제 | M8 |
| ST-09 | 알림 | 리마인더 알림 켜기(권한 요청), 알림 시각 기본값 | M10 |
| ST-10 | 사이트 | 게시된 페이지 관리 | M9 |
| ST-11 | 정보 | 버전, 변경 로그, 오픈소스 라이선스, 문제 신고 링크 | M11 |
| ST-12 | 고급 | 개발자 옵션: 디버그 로그, 기능 플래그 (AppFlowy `feature_flags`) | M0 |

데스크탑은 모달 대화상자(왼쪽 섹션 목록)이고, 폰은 화면 스택입니다.

## 2. 알림·리마인더 (`NT`, M10)

AppFlowy `notifications/*`에 해당합니다.

| ID | 기능 |
|---|---|
| NT-01 | 받은 알림함: 리마인더 목록(예정/지난), 읽음 표시, 모두 읽음, 해당 블록으로 이동 |
| NT-02 | 리마인더 출처: 날짜 멘션(ED-I05), DB 날짜 셀 리마인더 (시각: 당일 9시, 1일 전, 사용자 지정) |
| NT-03 | 앱이 열려 있을 때: 인앱 토스트 + 시스템 알림(Notification API) |
| NT-04 | 앱이 닫혀 있을 때: Web Push. Worker Cron(1분)이 KV에 저장된 다음 알림 시각을 확인하고 푸시. KV에는 `{pushSubscription, fireAt, title}`만 저장합니다 (본문 저장 안 함). 사용자가 켜야 동작 |
| NT-05 | 폰 하단 탭 배지 (안 읽은 수) |

## 3. 가져오기 (`IO`)

AppFlowy `sidebar/import/import_type.dart` 기준입니다. 모든 파싱은 `import.worker.ts`에서 합니다.

| ID | 형식 | 결과 | 마일스톤 |
|---|---|---|---|
| IO-01 | Markdown (`.md`, 여러 파일) | 문서 (GFM: 표, 할 일, 코드, 이미지는 상대 경로면 함께 선택된 파일에서 업로드) | M8 |
| IO-02 | 텍스트 (`.txt`) | 문서 (줄 → 문단) | M8 |
| IO-03 | CSV | 데이터베이스 (DB-IO) | M6 |
| IO-04 | Notion 내보내기 zip (Markdown & CSV) | 페이지 트리 + DB, 내부 링크를 멘션으로 변환 | M8 |
| IO-05 | WebNota 백업 zip | 워크스페이스 복원 (SY-07) | M8 |
| IO-06 | HTML (붙여넣기·파일) | 문서 (DOMPurify로 정리) | M8 |

## 5. 템플릿 (`IO-07`, M8)

- 기본 제공: 회의록, 할 일, 독서 목록(DB), 프로젝트 칸반(Board), 일정(Calendar), 일기, 위키 홈.
- 템플릿은 앱 번들 안의 JSON입니다 (지연 로드). 새 뷰를 만들 때 고를 수 있습니다.
- 내 페이지를 템플릿으로 저장하는 기능은 P2입니다.
