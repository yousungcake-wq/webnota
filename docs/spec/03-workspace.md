# 03. 워크스페이스, 사이드바, 탐색 (`WS`)

우선순위 표기: **P0** = 해당 마일스톤 필수, **P1** = 같은 마일스톤 내 권장, **P2** = 후순위.

## WS-01 워크스페이스 (P0, M1)

- 워크스페이스 = GitHub 데이터 저장소 1개. 기본 이름은 `webnota-data`, 추가 시 `webnota-<slug>`입니다.
- 기능: 만들기, 이름·아이콘 바꾸기, 전환, 목록(사이드바 상단 드롭다운), 연결 해제(로컬 데이터 유지 여부 선택), 다른 사람의 워크스페이스 열기(협업자로 초대받은 저장소 입력).
- 로그인 전에는 "로컬 워크스페이스" 하나만 있습니다. GitHub 연결 시 이 워크스페이스를 새 저장소로 업로드합니다 (현재 동작).
- 로컬 저장소 분리: IndexedDB 이름에 워크스페이스 ID 접두사를 붙입니다 (`wn:<wsId>:doc/<id>`).
- 전환 시 열려 있는 Y.Doc을 모두 언로드합니다.
- 구현 (M1-15): 워크스페이스 = 기기 로컬 슬롯(`core/docs/slots.ts`), 전환은 현재 슬롯을 바꾸고 새로고침(문서·탭 중계·리더 잠금이 모두 새로 잡힘). 워크스페이스별 localStorage 키는 `wsKey()` — 기기의 첫 슬롯은 기존 키 이름 그대로(legacy), 이후 슬롯은 `webnota:<wsId>:<키>`. 새 워크스페이스: 빈 워크스페이스(나중에 연결하면 `webnota-<이름>` 저장소 생성) 또는 저장소 열기(`owner/repo`, 첫 시작 때 연결; 남의 저장소는 이미 있어야 함). 제거는 이 기기의 DB·키만 지우고 저장소는 그대로. 사이드바 맨 위가 전환기, 설정 첫 카드가 워크스페이스 설정(ST-02).

- 경로 (M1-17): 뷰는 `#/w/<wsId>/v/<viewId>`. `wsId`는 기기 로컬 슬롯 ID라, 다른 기기에서 복사한 링크는 모르는 ID로 보고 현재 워크스페이스에서 뷰를 엽니다. 이 기기의 다른 워크스페이스 ID면 그 워크스페이스로 전환합니다. PoC 링크 `#/page/<id>`는 새 형식으로 바꿉니다(주소창 교체). 블록 링크는 뒤에 `/b/<blockId>`를 붙입니다 (M2-13, ED-F15).

## WS-02 스페이스 (P0, M1)

> 피드백 7 (2026-11-27): 데스크탑 사이드바는 **모든 스페이스를 나열**하고 각 스페이스가 접히는 구역입니다(접힘 상태는 기기·워크스페이스별 `spaces-folded`). 구역 머리(이름)를 끌어 순서를 바꾸고, `⋯`는 스페이스 설정·새 스페이스, `+`는 그 스페이스에 새 페이지. 폰은 홈의 스페이스 탭/전환 메뉴를 유지하고, 메뉴의 "스페이스 순서 바꾸기"(위·아래)로 순서를 바꿉니다.

AppFlowy `sidebar/space`에 해당합니다.
- 워크스페이스 안의 최상위 그룹이며 이름, 아이콘, 색상을 가집니다.
- 공개 범위: `shared`(워크스페이스 멤버 모두에게 표시) / `private`(나에게만 표시). private는 표시 필터일 뿐이고, 저장소 접근 권한이 있으면 데이터는 볼 수 있다는 점을 UI에 명시합니다.
- 기능: 만들기, 수정, 순서 변경, 삭제(하위 뷰 휴지통 이동), 스페이스 간 뷰 이동.
- 사이드바에는 스페이스 전환기(드롭다운)를 둡니다. AppFlowy처럼 한 번에 한 스페이스를 표시합니다.
- 구현 (M1-05): 전환기는 사이드바·폰 홈의 트리 머리. 현재 스페이스는 기기별(`webnota:space`), 없거나 안 보이면 첫 스페이스. 설정 대화상자: 이름, 이모지 아이콘(없으면 이름 첫 글자), 색 9가지, 나만 보기, 위/아래 순서, 삭제(마지막 스페이스는 삭제 불가). 스페이스 간 뷰 이동은 이동 대화상자(WS-12)로.

## WS-03 사이드바 뷰 트리 (P0, M1)

> 피드백 7: 들여쓰기는 목록 폭에 맞춰 최대 깊이에서 멈추고(제목 약 70px·`⋯`·`+` 자리 확보), 그보다 깊은 단계는 아이콘 앞에 단계마다 `·`를 표시합니다 — 하위 페이지를 무한히 만들 수 있음.

| 기능 | 데스크탑 | 터치 |
|---|---|---|
| 펼치기/접기 | ▸ 클릭 | ▸ 탭 |
| 열기 | 클릭 | 탭 |
| 새 하위 뷰 | 호버 시 `+` → 메뉴 (문서 / Grid / Board / Calendar) | 항상 보이는 `+` → 하단 시트 |
| 더보기 | 호버 시 `⋯` / 우클릭 | `⋯` / 길게 누르기 |
| 이름 바꾸기 | 더블클릭 인라인 편집 / F2 | 더보기 → 이름 바꾸기 (시트 입력) |
| 순서 변경, 다른 부모로 이동 | 드래그 앤 드롭 (위/아래/안으로, 들여쓰기 미리보기) | 길게 누른 뒤 드래그, 또는 더보기 → "이동" |
| 펼침 상태 | 기기별 저장 | 동일 |

더보기 메뉴 (AppFlowy `view_more_action_button` 기준):
이름 바꾸기, 아이콘 변경, 즐겨찾기 추가/제거, 복제, 이동(WS-12), 링크 복사, 새 탭에서 열기(데스크탑), 잠금/잠금 해제(WS-13), 휴지통으로 이동, 정보(작성자, 생성/수정 시각, 글자 수).

드래그 구현 (M1-03): 라이브러리 없이 포인터 이벤트로 처리합니다. 마우스는 5px 움직이면, 터치는 400ms 길게 누르면 시작하고, 드래그 모듈(`features/sidebar/drag.ts`)은 그때 지연 로드합니다. 행의 위 1/4·가운데·아래 1/4 = 위/안으로/아래, 접힌 부모 위에 0.6초 머무르면 펼침, 가장자리 자동 스크롤, Esc 취소. 키보드: 행에 포커스 후 `Alt+Shift+↑↓`(순서), `Alt+Shift+→/←`(들여쓰기/내어쓰기).

성능: 트리는 평탄화한 배열을 가상 스크롤로 렌더링합니다 (뷰 1,000개 이상에서도 60fps). 행 컴포넌트는 `memo` + 뷰별 셀렉터 구독을 씁니다.

## WS-07 검색 / 명령 팔레트 (P0, M1)

AppFlowy `command_palette`에 해당합니다.
- `Ctrl/⌘+K` (데스크탑), 폰은 하단 탭 "검색"입니다.
- 결과: 뷰 제목 + **본문 전문 검색** + DB 행의 기본 필드. 일치 부분을 강조하고 경로를 표시합니다.
- 입력이 없으면 최근 항목을 보여줍니다.
- 키보드: ↑↓ 이동, Enter 열기, `⌘+Enter` 새 탭.
- 데스크탑에서는 결과를 선택하면 오른쪽에 미리보기를 보여줍니다 (P2).
- 명령도 검색할 수 있습니다: "새 페이지", "다크 모드", "설정 열기" 등 (P1).

구현:
- Web Worker 안의 MiniSearch를 씁니다. 한글은 토스 **es-hangul**로 자모 분해: 단어의 모든 접미사를 자모로 + 초성으로 색인하고, 검색어도 자모로 바꿔 접두어로 맞춥니다. 그래서 단어 안쪽 일치("의록"), 입력 중인 글자("삭" → 사과, "회읠" → 회의록), 초성("ㅎㅇㄹ" → 회의록)이 모두 됩니다. 색인 형식이 바뀌면(`INDEX_FORMAT`) 저장된 색인을 버리고 다시 만듭니다.
- 제목 필터(팔레트·검색 화면·이동 대화상자·`@` 멘션·`/` 메뉴·이모지)도 같은 규칙(`core/text/hangul.ts`의 `matchRange`/`hangulIncludes`)을 씁니다. 강조 표시도 같은 함수로 범위를 찾습니다.
- 인덱스는 IndexedDB에 저장하고, 문서 변경 시 해당 문서만 증분 갱신합니다 (디바운스 2초).
- 아직 로드되지 않은 문서는 유휴 시간에 순차 인덱싱합니다.
- 구현 (M1-09): `features/search/engine.ts`(순수, 테스트) + `search.worker.ts` + `client.ts`. 문서별 버전 = Y 상태 벡터. 앱 시작 후 유휴 시간에 살아 있는 뷰를 하나씩 열어 버전·제목을 비교하고 바뀐 것만 다시 인덱싱(처음엔 전부). 열린 문서의 변경·제목 변경은 2초 뒤 반영. 인덱스는 `wn:<wsId>:search` IndexedDB(변경 2초 뒤 저장, pagehide 시 저장). 검색어의 각 단어가 모두 일치(접두어)해야 하고, 제목 일치는 인덱스와 별개로 즉시 표시합니다.

## WS-10 사이드바 레이아웃 (P0, M1)

> 피드백 6·7·12: 위에 WebNota 로고, 아래에 설정·휴지통·워크스페이스 전환·동기화 상태(하단 "새 페이지" 버튼은 제거). 접기는 모든 화면에서 같은 동작 — 접으면 왼쪽 위 "사이드바 열기" 버튼(누르면 다시 고정, 마우스를 올리면 잠깐 펼침)과 화면 왼쪽 24px 영역(올리면 펼침, 벗어나면 접힘). 접고 펼 때 미끄러지는 애니메이션. 고정된 사이드바가 있을 때는 펼침 사이드바를 띄우지 않음(두 개가 동시에 뜨던 버그 수정).

- 폭 조절(드래그, 200~480px, 기기별 저장), 접기/펴기(`⌘+\`).
- 데스크탑에서 접힌 상태로 왼쪽 가장자리에 호버하면 오버레이로 펼칩니다 (AppFlowy `slider_menu_hover_trigger`).
- 태블릿 세로 모드에서는 오버레이 드로어 + 왼쪽 가장자리 스와이프로 엽니다.
- 구현 (M1-12): `app/DesktopShell.tsx`. 폭은 드래그·더블클릭(기본값)·키보드 ←→로 조절, `webnota:sidebar`에 접힘과 함께 저장. 접힌 상태에서 왼쪽 10px 가장자리에 마우스를 올리면 오버레이로 펼치고, 사이드바 폭+40px 밖으로 벗어나면 0.3초 뒤 닫습니다. 태블릿(768~1023px + 터치)은 항상 드로어이며, 이동하면 닫힙니다.

## WS-14 단축키 (P0, 누적)

| 단축키 | 동작 |
|---|---|

구현 (M1-18): `app/shortcuts.ts`(새 페이지·테마·뒤로/앞으로·도움말), `⌘K`는 팔레트, `⌘\`는 DesktopShell, F2·`Alt+Shift+화살표`는 트리 행. `⌘N`은 브라우저가 가로채는 경우가 많아 `⌘⌥N`도 받습니다. 도움말 대화상자는 `⌘/`.

단축키는 설정에서 사용자 지정할 수 있습니다 (ST-07).
