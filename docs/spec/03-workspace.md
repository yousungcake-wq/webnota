# 03. 워크스페이스, 사이드바, 탐색 (`WS`)

우선순위 표기: **P0** = 해당 마일스톤 필수, **P1** = 같은 마일스톤 내 권장, **P2** = 후순위.

## WS-01 워크스페이스 (P0, M1)

- 워크스페이스 = GitHub 데이터 저장소 1개. 기본 이름은 `webnota-data`, 추가 시 `webnota-<slug>`입니다.
- 기능: 만들기, 이름·아이콘 바꾸기, 전환, 목록(사이드바 상단 드롭다운), 연결 해제(로컬 데이터 유지 여부 선택), 다른 사람의 워크스페이스 열기(협업자로 초대받은 저장소 입력).
- 로그인 전에는 "로컬 워크스페이스" 하나만 있습니다. GitHub 연결 시 이 워크스페이스를 새 저장소로 업로드합니다 (현재 동작).
- 로컬 저장소 분리: IndexedDB 이름에 워크스페이스 ID 접두사를 붙입니다 (`wn:<wsId>:doc/<id>`).
- 전환 시 열려 있는 Y.Doc을 모두 언로드합니다.

## WS-02 스페이스 (P0, M1)

AppFlowy `sidebar/space`에 해당합니다.
- 워크스페이스 안의 최상위 그룹이며 이름, 아이콘, 색상을 가집니다.
- 공개 범위: `shared`(워크스페이스 멤버 모두에게 표시) / `private`(나에게만 표시). private는 표시 필터일 뿐이고, 저장소 접근 권한이 있으면 데이터는 볼 수 있다는 점을 UI에 명시합니다.
- 기능: 만들기, 수정, 순서 변경, 삭제(하위 뷰 휴지통 이동), 스페이스 간 뷰 이동.
- 사이드바에는 스페이스 전환기(드롭다운)를 둡니다. AppFlowy처럼 한 번에 한 스페이스를 표시합니다.

## WS-03 사이드바 뷰 트리 (P0, M1)

| 기능 | 데스크탑 | 터치 |
|---|---|---|
| 펼치기/접기 | ▸ 클릭 | ▸ 탭 |
| 열기 | 클릭 | 탭 |
| 새 하위 뷰 | 호버 시 `+` → 메뉴 (문서 / Grid / Board / Calendar) | 항상 보이는 `+` → 하단 시트 |
| 더보기 | 호버 시 `⋯` / 우클릭 | `⋯` / 길게 누르기 |
| 이름 바꾸기 | 더블클릭 인라인 편집 / F2 | 더보기 → 이름 바꾸기 (시트 입력) |
| 순서 변경, 다른 부모로 이동 | 드래그 앤 드롭 (위/아래/안으로, 들여쓰기 미리보기) | 길게 누른 뒤 드래그, 또는 더보기 → "이동" |
| 펼침 상태 | 기기별 저장 | 동일 |

더보기 메뉴 (AppFlowy `view_more_action_button` 기준):
이름 바꾸기, 아이콘 변경, 즐겨찾기 추가/제거, 복제, 이동(WS-12), 링크 복사, 새 탭에서 열기(데스크탑), 잠금/잠금 해제(WS-13), 휴지통으로 이동, 정보(작성자, 생성/수정 시각, 글자 수).

드래그 구현 (M1-03): 라이브러리 없이 포인터 이벤트로 처리합니다. 마우스는 5px 움직이면, 터치는 400ms 길게 누르면 시작하고, 드래그 모듈(`features/sidebar/drag.ts`)은 그때 지연 로드합니다. 행의 위 1/4·가운데·아래 1/4 = 위/안으로/아래, 접힌 부모 위에 0.6초 머무르면 펼침, 가장자리 자동 스크롤, Esc 취소. 키보드: 행에 포커스 후 `Alt+Shift+↑↓`(순서), `Alt+Shift+→/←`(들여쓰기/내어쓰기).

성능: 트리는 평탄화한 배열을 가상 스크롤로 렌더링합니다 (뷰 1,000개 이상에서도 60fps). 행 컴포넌트는 `memo` + 뷰별 셀렉터 구독을 씁니다.

## WS-04 즐겨찾기 (P0, M1)

- 사용자별입니다 (`users[login].favorites`). 사이드바 상단에 "즐겨찾기" 섹션을 두고, 드래그로 순서를 바꿉니다.
- 폰에서는 하단 탭 "즐겨찾기"입니다.

## WS-05 최근 항목 (P1, M1)

- 기기별로 최근 연 뷰 30개를 저장합니다. 명령 팔레트와 폰 홈 상단에 표시합니다.

## WS-06 휴지통 (P0, M1)

- 목록, 복원, 영구 삭제, 모두 복원, 모두 비우기(확인 대화상자)를 제공합니다.
- 30일 지난 항목 자동 비우기 옵션(기본 꺼짐)을 둡니다.
- 삭제된 뷰를 열면 "휴지통에 있는 페이지입니다 [복원] [영구 삭제]" 배너와 함께 읽기 전용으로 보여줍니다.

## WS-07 검색 / 명령 팔레트 (P0, M1)

AppFlowy `command_palette`에 해당합니다.
- `Ctrl/⌘+K` (데스크탑), 폰은 하단 탭 "검색"입니다.
- 결과: 뷰 제목 + **본문 전문 검색** + DB 행의 기본 필드. 일치 부분을 강조하고 경로를 표시합니다.
- 입력이 없으면 최근 항목을 보여줍니다.
- 키보드: ↑↓ 이동, Enter 열기, `⌘+Enter` 새 탭.
- 데스크탑에서는 결과를 선택하면 오른쪽에 미리보기를 보여줍니다 (P2).
- 명령도 검색할 수 있습니다: "새 페이지", "다크 모드", "설정 열기" 등 (P1).

구현:
- Web Worker 안의 MiniSearch를 씁니다. 토크나이저는 공백 분리 + 한글 bigram입니다 ("회의록" → 회의, 의록).
- 인덱스는 IndexedDB에 저장하고, 문서 변경 시 해당 문서만 증분 갱신합니다 (디바운스 2초).
- 아직 로드되지 않은 문서는 유휴 시간에 순차 인덱싱합니다.

## WS-08 탭 (P2, M11)

- 데스크탑에서 여러 뷰를 탭으로 엽니다 (AppFlowy `home/tabs`). `⌘+클릭` / 중간 클릭으로 새 탭에서 엽니다. 탭 목록은 기기별로 저장합니다.

## WS-09 브레드크럼과 상단 바 (P0, M1)

- 경로(조상 뷰) 클릭 이동, 긴 경로는 가운데 생략 `…`.
- 상단 바 오른쪽: 동기화 상태, 공유 버튼(M9), 즐겨찾기 ☆, 더보기.
- 더보기(페이지): 페이지 스타일(글꼴, 크기, 전체 폭), 잠금, 복제, 이동, 내보내기, 기록(M9), 휴지통으로 이동.

## WS-10 사이드바 레이아웃 (P0, M1)

- 폭 조절(드래그, 200~480px, 기기별 저장), 접기/펴기(`⌘+\`).
- 데스크탑에서 접힌 상태로 왼쪽 가장자리에 호버하면 오버레이로 펼칩니다 (AppFlowy `slider_menu_hover_trigger`).
- 태블릿 세로 모드에서는 오버레이 드로어 + 왼쪽 가장자리 스와이프로 엽니다.

## WS-11 새 뷰 만들기 (P0, M1~M5)

- 문서 / Grid / Board / Calendar 중 선택합니다. 템플릿(IO-07)도 선택할 수 있습니다.
- 사이드바 하단 "새 페이지" 버튼, 폰은 FAB입니다.

## WS-12 이동 대화상자 (P0, M1)

- 스페이스와 트리를 검색할 수 있는 선택기입니다. 자기 자신과 자손은 선택할 수 없습니다.

## WS-13 페이지 잠금 (P1, M2)

- `locked=true`이면 에디터와 DB를 읽기 전용으로 만들고, 상단에 🔒 표시를 합니다. 잠금 해제는 버튼 하나로 합니다.

## WS-14 단축키 (P0, 누적)

| 단축키 | 동작 |
|---|---|
| `⌘K` | 검색 |
| `⌘N` | 새 페이지 (브라우저 충돌 시 `⌘⌥N`) |
| `⌘\` | 사이드바 토글 |
| `⌘⇧L` | 테마 토글 |
| `⌘[` / `⌘]` | 뒤로 / 앞으로 |
| `⌘/` | 단축키 도움말 |
| `F2` | 이름 바꾸기 |

단축키는 설정에서 사용자 지정할 수 있습니다 (ST-07).
