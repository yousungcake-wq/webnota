### QA용 디버그 플래그

브라우저 콘솔에서 `localStorage.setItem('webnota:debug', 'crash-editor')` 후 새로고침하면 에디터 렌더링 오류를 흉내 냅니다 (`crash-sidebar`도 가능, 쉼표로 여러 개). `schema-newer`는 데이터가 앱보다 새 버전인 상황(읽기 전용 + 업데이트 배너, spec/02 §6)을 흉내 냅니다 — 데이터는 바꾸지 않습니다. `seed-v1`은 처음 한 번 PoC(v1) 형식 데이터(페이지 3개, 즐겨찾기 1개, 본문 1개)를 IndexedDB에 심어 v2 마이그레이션을 확인합니다 — **빈 브라우저 프로필에서만** 쓰세요. `seed-many`는 한 번 페이지 300개(하위 20개 묶음 포함)를 추가합니다(가상 스크롤 확인). `seed-unknown`은 한 번 "Unknown content test" 페이지(모르는 블록·마크 포함, ED-B23)를 추가합니다. `seed-db`는 한 번 "QA database 50"(M4 필드 타입 전부, 50행), `seed-db-10k`는 "QA database 10000"(20필드 × 10,000행, 성능 확인)을 추가합니다 — 설정 → 고급의 "데이터베이스 (개발 중)"도 켜세요. 확인 후 `localStorage.removeItem('webnota:debug')`.

## 마일스톤별 추가 항목

마일스톤을 시작할 때 이 아래에 추가합니다.

### M0 (데이터 마이그레이션 — 실제 데이터가 있는 기기에서 꼭 확인)

- [ ] PoC(v0.1.0)로 쓰던 기기에서 새 버전을 열면 페이지 트리·순서·아이콘·본문·즐겨찾기·휴지통이 그대로다 (M0-16)
- [ ] 같은 기기에서 새로고침·앱 재실행 후에도 그대로다 (IndexedDB `page/`→`doc/` 복사)
- [ ] GitHub 연결된 두 기기: 한 기기를 먼저 업데이트하고 동기화한 뒤, 업데이트 전 기기(캐시된 앱)에서 동기화해도 저장소의 `data/pages/*.yjs` 파일이 사라지지 않는다
- [ ] 새 기기(빈 브라우저)에서 연결·첫 동기화 후 기존 페이지가 모두 나타난다
- [ ] 동기화 후 GitHub 저장소에 `data/docs/*.yjs`가 생기고 `data/pages/`는 사라진다 (M0-17)
- [ ] 같은 브라우저에서 탭 두 개: 한쪽 편집이 다른 쪽에 바로 보이고, 동기화는 한 번만 일어난다 (설정 → 동기화 기록, M0-23)
- [ ] 설정 → 동기화 기록에 결과가 쌓인다. 비행기 모드로 실패를 만든 뒤 온라인으로 돌아오면 바로 다시 시도한다 (M0-21, M0-24)
- [ ] 홈 화면에 설치: Android 런처·iOS 홈 화면 아이콘이 PNG로 선명하다. 아이콘을 길게 누르면 "새 페이지"·"검색" 바로가기 (Android) (M0-26)
- [ ] `webnota:debug=schema-newer`: 읽기 전용 배너와 "앱 업데이트" 버튼이 폰에서 가려지지 않는다 (M0-15)

### M1 (워크스페이스와 탐색)

- [ ] 사이드바: 페이지를 끌어서 순서 바꾸기·다른 페이지 안으로 넣기 (마우스). 폰 홈 트리: 길게 누른 뒤 끌기
- [ ] 이름 바꾸기: 데스크탑 더블클릭·F2, 폰 더보기 → 이름 바꾸기 (대화상자)
- [ ] 더보기 메뉴: 링크 복사 → 다른 탭에 붙여넣어 열림, 잠그기/해제, 정보, 이동(다른 페이지·다른 스페이스)
- [ ] 스페이스: 새 스페이스 만들기·전환·이름/색 바꾸기·삭제(안의 페이지는 휴지통). 폰 홈 위쪽 스페이스 탭
- [ ] 즐겨찾기: 별표 → 사이드바·폰 즐겨찾기 탭, 끌어서 순서 바꾸기
- [ ] 검색: ⌘K(데스크탑) / 검색 탭(폰)에서 본문 단어·한글 단어 일부로 찾기, 일치 부분 강조
- [ ] 아이콘: 이모지 전체 목록·한글 검색·피부색, 아이콘 탭(색)
- [ ] 휴지통: 모두 복원·비우기, 휴지통 페이지 열면 배너
- [ ] 사이드바 폭 끌기·접기(⌘\)·접힌 상태에서 왼쪽 끝에 마우스 → 펼쳐짐. 태블릿: 왼쪽 끝에서 밀어서 열기
- [ ] 워크스페이스: 새 워크스페이스 → 따로 데이터, 다시 전환하면 원래 페이지. (GitHub 연결 시) 다른 사람 저장소 열기
- [ ] 폰 홈: 최근 항목 가로 카드, 워크스페이스 전환, 설정 바로가기

### M2 (에디터 완성 — 텍스트)

에디터 기능이 많아서 데스크탑과 폰을 나눴습니다. 공통 Q1~Q7은 표, 목록, 토글, 다단 안에서도 확인해 주세요.

**데스크탑**
- [ ] `/` 메뉴: 한글·영어로 찾기, 최근 사용 위쪽. 제목 1~6, 토글(·제목), 콜아웃, 코드(언어·줄 바꿈·복사), 표, 2~4단, 목차, 하위 페이지
- [ ] 서식 버블: 링크 추가, 링크 위 버블(열기·복사·수정·제거), 글자 색·배경색(사용자 지정 색 포함), 위·아래 첨자(⌘. ⌘,)
- [ ] `@` 멘션: 페이지(제목 바꾸면 따라 바뀜, 휴지통이면 줄 긋기)·날짜(오늘·내일·12/1), `[[` 페이지 링크, `:웃음` 이모지
- [ ] 블록 핸들(⋮⋮) 클릭 → 블록 메뉴: 바꾸기, 색, 정렬, 텍스트 방향, 블록 링크 복사(다른 페이지에 붙여 넣고 누르면 이동·강조), 복제, 삭제
- [ ] 여러 블록 선택: Esc, Shift+↑↓, 여백에서 끌기 → 한꺼번에 색·삭제·복제, ⌘C/⌘V
- [ ] 붙여넣기: 다른 앱의 Markdown(제목·목록·할 일·표·코드), 웹 페이지 HTML, VS Code 코드(색 없이 텍스트로), URL(빈 곳 → 링크, 선택 위 → 선택을 링크로)
- [ ] ⌘F 찾기/바꾸기(대소문자, 모두 바꾸기 → ⌘Z 한 번에 복구), 실행 취소가 문단 단위로 되돌아감
- [ ] Tab: 토글 바로 아래 줄 → 토글 안, 목록 바로 아래 줄 → 마지막 항목 아래. Shift+Tab으로 꺼내기
- [ ] 페이지 더보기 → 페이지 스타일(글꼴·크기·줄 간격·전체 폭), 커버 추가·변경·이미지 링크·위치 조정, 잠그기 → 배너
- [ ] 표: 열 너비 끌기, 표 메뉴(행·열 추가·삭제, 머리글, 셀 색, 정렬)

**폰 (Android Chrome, iPhone Safari)**
- [ ] 키보드 도구 모음 v3: `+`(빈 줄은 바꾸고 아니면 아래에 추가), `Aa`(서식·제목·정렬·형광펜·색상), 링크, 들여쓰기(목록·토글), 블록 메뉴 버튼
- [ ] 텍스트를 선택하면 도구 모음 위에 복사·자르기·붙여넣기·굵게·링크·색상 줄 — OS 선택 메뉴와 겹치지 않는지, 붙여넣기 권한 요청이 자연스러운지
- [ ] 입력 중이 아닐 때 블록 길게 누르기 → 블록 메뉴 시트. 입력 중 길게 누르기는 원래대로 텍스트 선택
- [ ] 긴 문서 끝에서 입력할 때 커서가 키보드·도구 모음에 가리지 않음 (특히 iPhone)
- [ ] 링크 탭 → 링크 시트, 날짜 칩 탭 → 날짜 바꾸기, 하위 페이지 블록 탭 → 이동
- [ ] 표 셀에서 입력·셀 이동, 표 메뉴 시트. 다단은 세로로 쌓여 보임
- [ ] 페이지 더보기 → 페이지에서 찾기, 페이지 스타일 시트, 커버 버튼(항상 보임)
- [ ] 한글 입력(Gboard, 삼성 키보드, iOS): 목록·할 일·토글 안·표 셀·콜아웃·코드 블록·멘션 뒤에서 받침·겹받침·빠른 연타

### M3 (미디어와 임베드)

**먼저**: GitHub 로그인 버튼과 링크 미리보기는 Worker가 필요합니다. README "2. GitHub로 로그인 버튼 켜기"대로 설정하면 Actions가 Worker를 배포합니다. Worker가 없으면 카드에 사이트 주소만 나옵니다(정상 동작).

**데스크탑**
- [ ] 이미지: `/이미지` → 업로드, 스크린샷 붙여넣기(⌘V), 파일 끌어 놓기. 크기 손잡이 끌기, 정렬 3가지, 크기 메뉴, 캡션, 바꾸기, 내려받기, 원본 보기, 삭제. 새로 고침해도 그대로
- [ ] 큰 사진(폰으로 찍은 4000px 이상): 올리면 긴 변 2560px·WebP로 줄어듦. 설정 → 파일과 이미지 → "이미지 원본 그대로 올리기"를 켜면 원본 그대로
- [ ] 파일: `/파일` → PDF·zip 등 첨부, 크기·아이콘, "업로드 대기" → 동기화 후 사라짐, 내려받기 파일 이름(**한글 파일 이름**이 그대로 저장되는지 — 자동 테스트 환경에서는 확인 불가), 25MB 넘는 파일은 안내
- [ ] 동영상: YouTube(시간 지정 링크 포함)·Vimeo 링크 재생, mp4 파일 올려 재생, 크기 메뉴
- [ ] 임베드: Figma, Google 지도(공유 → 지도 퍼가기 주소), CodePen, Spotify, Loom이 보이고 조작됨. 다른 사이트 주소는 거절 안내
- [ ] 수식: 빈 줄 `$$`+공백, `/수식`, 문장 안 `$x^2$`, "$5 와 $10"은 그대로 글자. 수식 클릭 → 편집(미리보기), 비우면 삭제. 다크 모드에서 잘 보임
- [ ] 빈 줄에 URL 붙여넣기 → 메뉴(링크로 두기·미리보기 카드·동영상/임베드·이미지). 미리보기 카드 제목·설명·이미지, 새로 고침, 링크로 바꾸기
- [ ] 커버: 커버 변경 → 이미지 올리기 → 위치 조정. 페이지 아이콘: 이미지 올리기 → 사이드바·브레드크럼에도 보임
- [ ] **GitHub 실제 동기화**: 이미지·파일 추가 후 동기화 → GitHub 저장소 `files/`에 `<긴 해시>.webp` 등이 같은 커밋으로 올라감 → 다른 기기(또는 다른 브라우저)에서 연결하면 이미지가 보임 → 페이지를 영구 삭제하고 설정 → "저장소 정리" → 그 파일만 지워짐
- [ ] 오프라인(와이파이 끔)에서 이미지 추가 → 바로 보임 → 다시 연결되면 업로드

**폰 (Android Chrome, iPhone Safari)**
- [ ] 블록 추가(`+`) → 이미지 → 업로드: 카메라 촬영·사진 앨범 선택 둘 다. iPhone HEIC 사진, 세로로 찍은 사진의 방향(EXIF 회전)이 맞는지
- [ ] 이미지 탭 → 도구 모음이 한 줄(가로 스크롤 없이 삭제까지 보임), 크기 시트, 캡션 입력 시 키보드가 가리지 않음
- [ ] 파일 블록 내려받기(Android 다운로드 폴더 / iOS 파일 앱), 동영상 전체 화면 재생
- [ ] 수식 편집 시트(완료 버튼), URL 붙여넣기 메뉴 시트, 아이콘 시트의 이미지 올리기
- [ ] 미디어가 많은 페이지의 스크롤이 부드럽고, 이미지가 로드될 때 글이 튀지 않음(비율 예약)

### M4 (데이터베이스 I: Grid)

**먼저**: 설정 → 고급 → "데이터베이스 (개발 중)"을 켭니다(M5에서 Board·Calendar까지 끝나면 플래그를 없앱니다). 새 페이지 `+` → "표 (Grid)". 많은 데이터는 디버그 플래그 `seed-db`(50행, 모든 필드 유형)·`seed-db-10k`(10,000행 × 20필드).

**데스크탑**
- [ ] 새 Grid: "이름" 필드와 빈 행 3개. 셀 클릭 → 다시 클릭(또는 Enter, 바로 입력)으로 편집, Enter 저장 후 아래로, Tab 오른쪽, Esc 취소, 텍스트 Shift+Enter 줄 바꿈. **한글 입력**(조합 중 Enter가 저장으로 처리되지 않는지)
- [ ] 필드 추가(헤더 끝 `+`): 숫자(통화 KRW·USD, 소수 자릿수, 백분율), 선택·다중 선택(옵션 만들기·색·이름·순서 끌기·삭제), 날짜(달력, 종료일, 시간 포함, 형식), 체크박스, 체크리스트, URL(열기·복사), 만든·수정한 시각, 소요 시간(`1h 30m`), 파일·미디어(사진·PDF 올리기, 썸네일)
- [ ] 필드 메뉴: 이름, 유형 바꾸기(값이 사라지면 "N개 셀" 확인 → 토스트의 실행 취소 30초), 숨기기, 복제, 삭제, 왼쪽/오른쪽 삽입, 줄 바꿈(행 높이 자동), 이 열까지 고정. 헤더 끌어 순서, 가장자리 끌어 폭
